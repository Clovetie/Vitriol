# M3 Garage detour: exact-cost lazy clearance (2026-10-13)

The Braid still uses the six **authored-map-derived** Garage perimeter nodes and its established shortest valid route. The old `GarageNavigation:route` raycast the blocked start-to-goal segment and then all six start→node plus all six node→goal segments **before** comparing their route costs. A cold Garage detour could therefore cost 13 workspace rays (12 if the preceding policy had supplied the actual obstruction). This is a possible contributor to an observed one-off `Creature:Think 8.313/1.000 ms` warning, **not an attributed cause**.

The route now calculates each candidate's **unchanged graph cost** before paying for that candidate's clearance ray. Once a safe pair has won, a start node is skipped only if *no* pair from it has a strictly lower exact cost; an end node is skipped if its exact pair cannot beat the winner. Candidate iteration order, original strict `<` tie rule, `routeClear` endpoint/boarded-gate safety, half-second cache and no-path fail-closed result are unchanged. A ray is **never** presumed clear because its mathematical cost is low: every prospective winning start/end segment is physically checked before selection. No extra game objects, larger budgets, changed gait, geometry, clues or hidden-prey information.

**Local proof:** `tools/vitriol/navigation.luau` contains an independently written exhaustive 6+6-ray route oracle. On 720 cold map-side start/goal pairs, the new function selected **exactly the same waypoint (including nil)** in all 720, and used no more rays on any case.
